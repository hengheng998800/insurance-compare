## 一、产品结构

**必选计划 8 项责任**（不可拆分）：①一般医疗及外购药械（300万）②重大疾病医疗及外购药械（300万，100种重疾）③特定疾病康复住院（100万，16种特定疾病）④质子重离子（300万）⑤特定药品（300万）⑥救护车费用 ⑦重疾异地转诊公共交通及住宿（1万）⑧在线问诊药品费（5000元）。国内医疗总保额 **600万元**。

**可选：特需医疗加油包**（398元/18-20岁 起，见费率表第三列）。

## 二、投保规则

| 项目 | 内容 |
|---|---|
| 初次投保年龄 | **18-80周岁**（均含）——与臻选（30天-105岁）的最大差异 |
| 81岁及以上 | 仅限上一张保单期满后指定期限内重新投保 |
| 最高重新投保年龄 | 105周岁 |
| 职业 | 无限制 |
| 健康告知 | 无（仅除外5类严重既往症+投保前已发生意外事故） |
| 限购 | 每人限1份 |
| 生效 | 投保成功次日零时 |

## 三、等待期（重点）

- 新发疾病：**30天**
- **一般既往症导致的保险事故：90天**
- 无等待期：在线问诊药品费、意外伤害、上一张保单期满后指定期限内重新投保
- 分期缴费未缴清上年度保费 → **次年等待期重新计算**（与臻选同款陷阱）

## 四、赔付规则（核心账）

**一般医疗（0免赔，分级累进）**：
- 0-2万（含）：60%；有社保投保未结算 → 36%
- 2万以上：100%；未结算 → 60%

**重疾医疗**：0免赔 100%（未结算60%）；**特需部/国际部/VIP部不支持医保结算的仍按100%**——这是中高端版的关键条款，特需部多数无法走医保，等于实际不受医保罚则影响。

**康复住院**：指定康复机构（33家）100%；公立/指定民营普通部 60%（未结算36%）。16种特定疾病确诊180日内。

**特药**：社保内100%（未结算60%）、社保外100%；基因检测：非指定机构发生仍100%赔付、限1万。

**在线问诊**：60%直付（自付40%），500元/次×12次/年=5000元上限，等待期0天。

**指定疾病×50%（仅新保，不间断重新投保不受限）**：良性肿瘤（含子宫肌瘤）、肺结核、息肉、增生、囊肿、结石、痔疮、肛瘘——一般医疗及特需医疗责任，算完再乘50%。

## 五、5类严重既往症除外（与臻选清单比对）

与臻选2026的除外清单**完全一致**（A肿瘤/B肝肾/C心脑血管糖脂代谢/D肺部/E其他+罕见病），释义逐条相同（高危结节=4级+/肺结节>8mm/高危表述；高血压伴并发症=高血压及全部并发症不赔）。另不赔：投保前或非连续重新投保前**已发生意外事故**的相关费用。

一般既往症药械锁：2026-4-30（含）前NMPA批准上市药品及其说明书适应症用法用量；2026-5-1后新批不赔（投保后初次确诊不受此限）。**此条2026-6-23起由"2025-12-31前"更新至"2026-4-30前"**（08号文件版本说明，对客户是放宽）。

## 六、特药与CAR-T

- 特药目录=合同失效日前NMPA批准上市的**靶向、免疫治疗药物**（不限固定清单，与臻选同机制）
- **7款CAR-T**：奕凯达、倍诺达（2021-9-10起）；福可苏（2024-1-5起）；源瑞达、赛恺泽、卡卫荻（2024-12-18起）；**普利得凯（2026-3-16起）**——比臻选多覆盖儿童适应症（普利得凯3~21岁 r/r B-ALL）。单年度累计限1次。
- 外购药械：无固定清单，=合同失效日前NMPA批准目录（www.nmpa.gov.cn），与臻选完全同机制。

## 八、重新投保规则（10号文件，打分页"续保稳定性"维度核心）

1. **一年期不保证续保**。
2. 众民保系列老客户：期满前60天或期满后30天内申请 → **无等待期**。
3. 方案映射：众民保中高端（含2026）→ 中高端2026 **不论有/无理赔均接受**；普惠/百万系列（经典/臻选/2025）→ **限无理赔**。
4. 停售不再接受，但提供迭代产品建议；超105周岁/不如实告知欺诈不再接受。

## 九、免责说明书（4号文件，8页）

通用免责与臻选同框架（故意伤害/自杀/犯罪/醉驾毒驾/高风险运动/性病精神病遗传病艾滋病/职业病医疗事故/整形美容/怀孕分娩/牙科/康复器具/胃减容术/肠道菌群移植/除9种外人工器官/基因疗法/战争核污染）。

特药与外购药械专项免责（9条）：未获NMPA批准或超说明书适应症；港台及境外治疗；未遵医嘱；耐药后继续购药；无关基因检测；未在指定药店购特药；未按流程申请或未过审；仅临床不适但入出院诊断均非约定疾病。

> 该说明书单独成文（8页），构成保险人履行提示说明义务的证据链。
